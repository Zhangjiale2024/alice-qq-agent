## 二、装 ffmpeg

GPT-SoVITS 依赖 ffmpeg 做音频读写与切分。三种方式任选：

1. **conda**（本机有 anaconda，最省事）

       conda install -c conda-forge ffmpeg

2. **官方提供的独立可执行文件**（README 里给的链接）

       https://huggingface.co/lj1995/VoiceConversionWebUI/blob/main/ffmpeg.exe
       https://huggingface.co/lj1995/VoiceConversionWebUI/blob/main/ffprobe.exe

   下下来放进项目根目录即可。

3. 自行下载 static build 并加进 PATH。

装完验证：ffmpeg -version

## 三、装 GPT-SoVITS

### 路线 A：Windows 整合包（推荐，最省事）

官方 README 明确给出：

    https://huggingface.co/lj1995/GPT-SoVITS-windows-package/resolve/main/GPT-SoVITS-v3lora-20250228.7z

中国地区下载入口见官方语雀文档：
https://www.yuque.com/baicaigongchang1145haoyuangong/ib3g1e/dkxgpiy9zb96hob4

整合包已含依赖与大部分模型，解压即用。**我没实际下过这个包**，只是照官方 README 转述。

### 路线 B：手动（README 的通用步骤）

    git clone https://github.com/RVC-Boss/GPT-SoVITS.git
    cd GPT-SoVITS

    conda create -n GPTSoVits python=3.10
    conda activate GPTSoVits

    pip install -r extra-req.txt --no-deps
    pip install -r requirements.txt
    conda install ffmpeg

### 预训练模型（README 第 1~5 条）

1. 从 https://huggingface.co/lj1995/GPT-SoVITS 下载预训练模型，
   放到 GPT_SoVITS/pretrained_models
2. G2PWModel.zip（HF 或 ModelScope），解压到对应位置
3. UVR5 权重（做人声/伴奏分离）：
   https://huggingface.co/lj1995/VoiceConversionWebUI/tree/main/uvr5_weights
   放到 tools/uvr5/uvr5_weights
4. FunASR 模型首次使用时自动下载
5. 英语/日语 ASR 可选：faster-whisper-large-v3 放到 tools/asr/models

**UVR5 对你有用**：它能把参考音频里的 BGM 和人声分开——
而你从游戏里录的中配/日配语音是**带背景音乐的**，这一步几乎必做。

## 四、准备参考音频

按你要的"中配 + 日配混合、偏日配"，需要准备：

| 用途 | 来源 | 建议 |
| --- | --- | --- |
| 主参考 | 中配（皛四白） | 5~10 秒，**去掉 BGM**，单声道 16k wav |
| 第二参考（音色融合） | 日配（田中美海） | 同样 5~10 秒，去 BGM |
| 情感参考（可选） | 双方各自的情绪片段 | 每种情绪一段，配好对应文本 |

**必须去掉 BGM**：否则生成出来会带杂音。用 UVR5 或任何分离工具处理。

**注意**（这点比技术更重要）：
你从游戏里录下来的语音，**版权在游戏发行方**——B 站上那些语音集的简介也写着
"版权归属于蔚蓝档案"。本地自己玩风险最低，但请**不要公开传播生成的音频**，
那会把它从"个人使用"变成"公开使用"。

## 六、项目侧配置

    TTS_PROVIDER=gptsovits
    TTS_CLONE_URL=http://127.0.0.1:9880
    TTS_CLONE_REF_AUDIO=D:/voices/alice_zh.wav        # 中配
    TTS_CLONE_REF_AUDIO_2=D:/voices/alice_ja.wav      # 日配
    TTS_CLONE_PROMPT_TEXT=主参考音频里逐字说的话
    TTS_LANGUAGE=zh
    TTS_FALLBACK=baidu                                 # 服务没起来时自动退回

    TTS_EMOTION_ENABLED=1
    TTS_EMOTION_REFS=happy=D:/voices/zh_happy.wav|音频里的话,sad=D:/voices/zh_sad.wav|音频里的话

**TTS_FALLBACK 强烈建议配**：本地服务是你自己起的一个进程，
没开机、崩了、模型还在加载，都会让语音直接消失。配了它就会退回免费 TTS，
并在 debug 里写明"克隆音色不可用，已退回"。

## 七、混合两个音色的两种路线（关键区别）

### 路线 1：GPT-SoVITS 参考融合（简单，但**没有权重**）

官方 api_v2 的参数是：

    "ref_audio_path": "",         # str.(required) 主参考
    "aux_ref_audio_paths": [],    # list.(optional) 多说话人音色融合

把日配放进 aux_ref_audio_paths，模型会把两个参考一起用作音色来源。

**但官方参数表里没有任何权重参数**——你没法写"日配 0.7 / 中配 0.3"。
所以这条路只能得到"一种混合音色"，调不出精确比例。
项目会在启动横幅里明确提示这一点，不会让你以为权重生效了。

### 路线 2：RVC 模型融合（能精确控制权重，**这才是"偏日配 0.7"的实现**）

    merged = 0.7 × model_日配 + 0.3 × model_中配

RVC WebUI 里叫「模型融合 / Model Fusion」。

配合本项目的双层结构：

    中文 TTS（保证中文发音正确）
        ↓
    RVC 混合音色（日配 0.7 + 中配 0.3）→ 只改音色，保留语调

项目配置：

    TTS_VC_URL=http://127.0.0.1:7890
    TTS_VC_MODEL=alice
    TTS_VC_BLEND=alice_ja:0.7,alice_zh:0.3

转换服务端契约（需你按所用 RVC 版本适配）：

    POST {TTS_VC_URL}/convert
    multipart: audio=<音频> model=alice blend=alice_ja:0.7,alice_zh:0.3

### 路线 3：按比例准备微调数据集（最"正宗"的加权混合）

要让 GPT-SoVITS 本身学出"偏日配"的音色，就按 **7:3 的时长比例**混合
日配与中配音频做微调数据。模型会按数据比例学到混合音色。
成本最高（需要 1 分钟以上干净音频），但效果最自然。

## 八、自检

项目内置了自检命令：

    python -m aliceqq --check-voice

实测输出示例：

    【语音链路自检】
      语音合成 = gptsovits｜注意 = GPT-SoVITS 参考融合无权重参数…
      [服务] 问题 连不上（URLError）——服务没启动？启动命令：python api_v2.py -a 127.0.0.1 -p 9880
      [主参考] data/voices/good.wav
          - 需人工确认：没有背景音乐、没有第二个人说话、没有爆音
      [第二参考（音色融合）] data/voices/wide.wav
          - 是 2 声道，建议转成单声道
      [情感参考] 共 3 个
          happy: 问题 data/voices/short.wav
              - 只有 1.2 秒，太短（建议 3~15 秒）
          sad: 问题 data/voices/fake.wav  （缺少该音频对应的文本…）
              - WAV 解析失败（file does not start with RIFF id）——扩展名是 wav 但内容不是？
          bad: 问题 data/voices/nope.wav
              - 文件不存在

它会查出：服务是否在跑、参考音频是否存在、是否单声道、采样率、
时长是否合适、是不是真 WAV、情感参考有没有配对应文本、权重配置有没有矛盾。

**查不出来的**（必须人工听）：有没有 BGM、有没有第二个人说话、有没有爆音。

## 九、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 语音没声音 | 本地服务没启动 | 配 TTS_FALLBACK=baidu；或启动 api_v2 |
| 生成音带杂音 | 参考音频有 BGM | 用 UVR5 分离后再做参考 |
| 中文带日式口音 | 用日配当了主参考 | 主参考必须用中配；日配只放 aux |
| 语气平板 | 没有情感参考音频 | 配 TTS_EMOTION_REFS |
| 混合比例调不出来 | GPT-SoVITS 参考融合无权重 | 改用 RVC 融合（路线 2） |
| 权重不生效 | 配了 TTS_VC_BLEND 但没配 TTS_VC_URL | --check-voice 会直接警告 |
