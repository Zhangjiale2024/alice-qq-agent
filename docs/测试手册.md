## 七、出问题怎么定位

| 症状 | 先看哪里 |
|---|---|
| 机器人完全没反应 | `run.py` 启动横幅是否打印；NapCat 是否连上（NoneBot 有 WS 连接日志） |
| 私聊能回、群里不回 | 群是否 `/授权`；`decision` 是 `denied` 还是 `silent`（`ALICE_DEBUG=1` 看决策日志） |
| 回复里出现"稍等/正在检索" | 诚实护栏没生效 → 检查 `aliceqq/honesty.py` 是否被正确导入 |
| 记忆串了 | 用不同 QQ 号分别发 `/记忆` 对比；再跑 `tests.test_engine` |
| 语音没发出来 | 先 `--check-voice`；再看回复里有没有"克隆音色服务没连上"（= 退回备用音色） |
| 语音出现了但不是爱丽丝音色 | 同上——`provider` 里带 `(备用)` 就是回退了 |
| 模型答非所问 | `--show-prompt` 看实际注入内容（十有八九是变量没渲染或知识库太杂） |
| 群管理动作没生效 | 看回复里的失败原因（机器人可能不是管理员）；`/审核` 看审计记录 |
| 测试莫名失败 | 先确认 `$env:PYTHONUTF8='1'`；再比代码指纹是否和记录一致 |

   按自己的「重连间隔」（当前 30 秒）发起新连接。另外 NapCat 存在
   **静默离线**问题（PR NapNeko/NapCatQQ#2080）：QQ 登录被踢但收不到通知，
   WS 看着正常却不收消息。两种情况表象相同、对策相反。
   排查工具：`python scripts\链路体检.py`（只读）。
3. **RVC 唱歌链路**。环境已搭好（独立 Python 3.10），整条流水线已跑通，
   但**没有自动化测试**，只有 `aliceqq/singing.py` 的意图识别/缓存/取消有覆盖。
   详见交接文档第十四~二十节。
3. **批量撤回未实现**（只有单条撤回）；`conversation_log` 不存 `message_id`。
4. **警告不会自动过期**，累计次数永久保留。
5. **反广告是规则式的**（关键词+正则+重复计数），不是模型判定。
   好处是可解释、误伤少；代价是绕开词表的广告抓不到。
6. **检索结果的真实性**只能靠"带来源 + 标注时效"约束，无法自动化验证。

## 九、把测试从"跑一遍"变成"可重复"

- **改代码后必须重算指纹**：`--test-plan` 结尾会打。把它连同测试结果记进
  交接文档，否则"上次全绿"这句话没有意义。
- **测试库残留会自动清理**：每个用例建一个 SQLite 目录，
  `tests/test_engine.py` 的 `_prune_stale_test_dirs()` 每次建库前清掉
  30 分钟前的（曾经累积到 10486 个目录 / 672MB）。
- **不要用 `Tee-Object ... | Select-Object -First N` 跑长任务**：
  拿够 N 条就关上游管道，会把测试进程掐死（表现为"卡住无输出"）。
  用后台作业 + 读输出，或直接 `python -u`。
